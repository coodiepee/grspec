# Docs Agent Instructions

Defines authoring standards for generated agent instruction documentation. The spec ensures that templates, examples, and validation checklists in generated docs are clear and copy-ready.

## Key Standards

- Templates use consistent formatting with clear section markers
- Examples are self-contained and directly usable
- Validation checklists are actionable with explicit pass/fail criteria
- Generated docs avoid implementation details that could become stale
