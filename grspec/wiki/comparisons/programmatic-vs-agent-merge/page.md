# Programmatic vs Agent Merge

A comparison of how spec changes are merged into main specs — programmatically via code vs. via an AI agent.

## Programmatic Merge (chosen for archive)

The `specs-apply.ts` module applies delta operations in a deterministic order:

1. Parse RENAMED → apply renames
2. Parse REMOVED → remove by header match
3. Parse MODIFIED → replace by header match
4. Parse ADDED → append new requirements

| Aspect | Assessment |
|--------|-----------|
| **Determinism** | Perfect — same input always produces same output |
| **Speed** | Fast — pure string processing, no LLM calls |
| **Error handling** | Precise — reports exact conflicts (missing headers, duplicates) |
| **Cost** | Free — no API calls |
| **Complex merges** | Limited — cannot resolve semantic conflicts |

## Agent-Driven Merge

An AI agent reads both the current spec and delta spec, then produces the merged result using natural language understanding.

| Aspect | Assessment |
|--------|-----------|
| **Determinism** | Low — different runs may produce different results |
| **Speed** | Slow — requires LLM inference |
| **Error handling** | Fuzzy — may silently resolve or introduce errors |
| **Cost** | Non-trivial — API costs per merge |
| **Complex merges** | Strong — can resolve semantic conflicts and rewrite for coherence |

## Decision Rationale

grspec uses programmatic merge for the archive workflow because:

1. **Reliability** — The structured delta format (ADDED/MODIFIED/REMOVED/RENAMED) maps cleanly to deterministic operations
2. **Speed** — No waiting for LLM responses during archive
3. **Cost** — No API costs for routine operations
4. **Auditability** — Each operation is logged with counts (X added, Y modified, Z removed)

## Where Agent Merge Fits

Agent-driven merge remains valuable for:

- **Conflict resolution** — When programmatic merge detects conflicts, an agent can suggest resolutions
- **Semantic coherence** — After programmatic merge, an agent can review the result for logical consistency
- **Wiki delta generation** — Wiki pages are generated by agents, so their merge uses agent understanding
