Use the wiki as a knowledge base to answer questions.

**Input**: The question to answer (e.g., `/grsx-wiki-query how does the archive flow work?`).

1. Read `grspec/wiki/index.md` to see the knowledge map.
2. Identify relevant pages based on the user's question.
3. Read those pages, following `[[wikilinks]]` as needed for deeper context.
4. Synthesize an answer grounded in wiki content.
5. If the answer reveals a gap, offer to create/update a wiki page.

**Key principle**: Navigate via index, don't dump the entire wiki into context.
